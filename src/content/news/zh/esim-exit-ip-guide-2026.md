装上旅行 eSIM 打开网站，互联网看到的 IP 地址未必是包装上印的那个国家。对注册账号、银行 App、AI 注册或看流媒体来说，真正起作用的是**出口 IP**：它的归属国家，以及它的性质——住宅、数据中心、商业宽带，还是运营商移动网络。

## 为什么旅行 eSIM 常常「IP 不对」

多数旅行 eSIM 聚合商并不给你发本地运营商的原生配置，而是把你的流量**漫游**到一个基础运营商，再在一个可能远在几千公里外的网关出口上网。

这一点有严格的学术测量背书。2024 年一项针对 Airalo 的研究（[arXiv 2408.14923](https://arxiv.org/html/2408.14923)）实测 24 张 eSIM，其中 21 张是漫游架构，公网 IP 落在新加坡 Singtel、法国 OVH（主机商）或美国 Packet Host——全是机房出口，不是本地住宅 IP。Holafly 官方 FAQ 也承认用户可能看到外国 IP，因为合作方用自家基础设施分配地址。

实际影响：

- 在屏蔽机房 IP 的平台注册可能失败
- 银行和 AI 服务可能把连接标记为代理
- 流媒体片库可能与物理所在地不匹配
- 出口在另一个大洲时，延迟和带宽都会受损

## 本站跟踪的四种 IP 性质

目录里每家供应商现在都维护一份**出口 IP 画像**：

1. **运营商移动 IP**——出口属于真实移动运营商网络（最像本地手机用户）
2. **住宅 IP**——家庭宽带 IP（常经家宽出口；注册账号最吃香）
3. **商业宽带 IP**——企业固定线路 IP
4. **数据中心 IP**——主机商 IP（OVH、AWS、Packet 等）；运营成本最低，也最容易被风控标记

每份画像都带置信度标签：已核实、较可信、不确定、社区口径。「社区口径」指单个用户的观察——运营商路由会变，当线索看，别当保证。

## 目录里的典型案例

- [Airalo](/zh/sims/airalo)——漫游架构；出口常见新加坡、法国或美国，且多落在主机商网络（机房 IP，学术测量已核实）

## 逐品牌：各家 eSIM 的 IP 落地在哪？

这些都是用户真实在搜的问题。答案综合学术测量、官方声明与社区报告，并附置信口径。

**Airalo 的 IP 在哪个国家？** 实测出口：新加坡 Singtel（AS45143，归国路由档）、法国 OVH（AS16276，里尔）与美国 Packet Host（AS54825，出口档）——机房 IP，且常常不是你所在的国家。Airalo 官方客服也确认无法保证 IP 位置。需要目的地国家 IP 的话，Airalo 不是合适的工具。

**Saily 的 IP？** 无可靠公开口径。官方博客只说流量经运营商服务器出公网、未披露落地；USENIX 2025 研究摘要将 Saily 列为不经中国网络的一档。按未知处理。

**Nomad 的 IP？** 多位 Reddit 用户独立报告出口为香港——包括在美国用美国套餐时（APAC 套餐据报走中国联通经香港回传）。无官方口径，IP 性质未知。

**Holafly 的 IP？** USENIX 2025 研究实测 Holafly 流量经中国大陆中国移动及未披露网络路由；Holafly 官方 traffic-routing FAQ 承认归国路由、会出现外国 IP。社区另报新加坡落地。出口是住宅还是机房无公开数据。

**Roamless 的 IP？** 用户口径一致：三个区域出口节点——欧洲（比利时/法国）、美国（Ashburn）、新加坡，由网络自动分配、用户不可选。「新加坡住宅 IP」的早期社区说法未能核实，性质按未知处理。

**英国虚商（giffgaff/VOXI/Lebara/Tesco）**：归国路由——漫游到哪出口都是真英国移动 IP。这也是英国保号卡同时被当作「英国 IP 注册工具」的原因。

## 如何自查 eSIM 出口 IP

1. 连上 eSIM 后打开任一 IP 查询站（ipinfo.io、ip.sb）
2. 记下显示的**国家**和 **ASN / 运营组织**
3. 组织是主机商（OVH、AWS、DigitalOcean、Packet、Google Cloud）即为机房出口
4. 是移动运营商或家庭宽带 ISP，则是移动或住宅出口

跨国移动后记得复查——部分供应商按目的地切换出口，路由也会随时间调整。

## 按 IP 画像选卡

如果你要让号码或连接看起来像本地手机用户——收验证码、注册 AI 服务、用银行——优先选出口是**目标国家移动或住宅 IP** 的供应商，避开机房出口。如果只是便宜上网看地图，IP 性质无所谓，哪个便宜买哪个。
