# SimDirs — Agent Guide

This project keeps **one** agent guide. `AGENTS.md` is the source of truth for
commands, the content schema, interaction rules, writing style, the visual
system and deployment notes.

This file used to be a hand-copied duplicate. It drifted: the copy below the
header was missing the interaction and visual sections entirely, so two agents
read two different rulebooks. It now imports the real file instead.
